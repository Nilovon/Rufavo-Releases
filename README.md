# Rufavo Downloads

Öffentliche Installationspakete und automatische Updates für Rufavo.

[Neueste Version herunterladen](https://github.com/Nilovon/Rufavo-Releases/releases/latest)

- **Windows x64:** Datei mit der Endung `-setup.exe` herunterladen und starten. Der Installer ist derzeit ohne Authenticode-Signatur; Windows kann einen unbekannten Herausgeber anzeigen.
- **Mac mit Apple Silicon (M1 oder neuer):** DMG mit `aarch64` im Namen öffnen und Rufavo in Programme ziehen.
- **Mac mit Intel-Prozessor:** DMG mit `x64` im Namen öffnen und Rufavo in Programme ziehen.

Die Mac-Pakete sind mit einer Developer ID signiert und von Apple notarisiert.
Die Update-Pakete aller Plattformen besitzen eine separate kryptografische Signatur, die die App vor der Installation prüft.
SHA-256-Prüfsummen stehen in `SHA256SUMS.txt` beim jeweiligen Release.

Installierte Apps laden Updates automatisch herunter. Installation und Neustart werden in der App bestätigt und sind während Gesprächen gesperrt.

Dieses Repository enthält ausschließlich Downloads und Hinweise. Der Quellcode wird privat verwaltet.
GitHubs automatisch erzeugte „Source code“-Archive enthalten nur den Inhalt dieses Download-Repositories.
